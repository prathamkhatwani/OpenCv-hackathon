# Real RDD2022 integration

The India portion of RDD2022 was downloaded from the authors' Figshare release and actually imported and used for visual training. This is separate from the synthetic interactive demo. The demo retains its explicit synthetic label and does not pretend to run live model inference.

Sources: [authors' repository](https://github.com/sekilab/RoadDamageDetector), [RDD2022 v1](https://doi.org/10.6084/m9.figshare.21431547.v1), [paper](https://arxiv.org/abs/2209.08538). Credit Arya et al., RDD2022: A multi-national image dataset for automatic Road Damage Detection. The specific Figshare release lists CC BY 4.0; the repository's general dataset section lists CC BY-SA 4.0. Both source notices are recorded here; raw images are not redistributed in this repository.

## Imported corpus

| Partition | Images | Pothole boxes (D40) |
|---|---:|---:|
| Train | 4,836 | 2,145 |
| Validation | 1,477 | 641 |
| Test | 337 | 170 |
| Total | 6,650 | 2,956 |

The supported taxonomy is D00 longitudinal crack, D10 transverse crack, D20 alligator crack and D40 pothole. 1,056 images with unsupported categories were quarantined rather than treating their unknown objects as background. See the checked-in summary for counts. The official unlabeled test images are excluded. JPEG dimensions and bounding boxes are checked, exact image duplicates removed, and contiguous filename blocks of 100 assigned deterministically to splits. These blocks are **not verified independent drives or physical sites**; reported metrics are a limited crop pilot, not competition detector accuracy or field validation.

Every imported record leaves telemetry, contact and impact association null. Absence of a shock label never becomes a negative pothole label. Exports include a provenance manifest, COCO annotations and YOLO labels/data.yaml, enabling a future learned proposal detector without inventing new annotations.

## Reproduce

From `roadreport/backend`, install `requirements-lock.txt`, then run:

```bash
python -m tools.download_rdd2022 --output data/downloads/RDD2022_India.zip
python -m app.datasets.rdd2022 --archive data/downloads/RDD2022_India.zip --output data/rdd2022-india
python -m tools.train_rdd_visual --data data/rdd2022-india --output app/models/rdd2022-visual.json
python -m pytest -q
```

The downloader fetches the 526,709,145-byte India member using verified HTTP ranges instead of downloading the full 13 GB multinational archive. It checks country size/CRC and all inner ZIP CRCs, and records SHA-256. It refuses an unexpected archive layout or a server that ignores ranges. The whole outer archive's MD5 is not verified. The importer requires a new/empty output directory. Data and partial downloads are Git-ignored. Download provenance and import summary are checked in under `docs/datasets/`; no dataset archive is committed.

## Bundled model and application behavior

OpenCV normalizes crops to 64×64; scikit-image computes 324 HOG features. A binary logistic model learns D40 versus other labeled damage and sampled unannotated road patches. Those background patches may contain missed annotations. Scaling is fitted on training data only; C is selected from 0.01/0.1/1 on validation log loss. Sigmoid calibration reuses validation, a stated limitation. Held-out test metrics, actual crop counts, dataset manifest hash and coefficient parity checks are recorded alongside `app/models/rdd2022-visual.json` in its `.metrics.json` model card.

The backend automatically loads this bundled visual model. `ROADREPORT_VISUAL_MODEL` overrides its path; setting it to `off` disables it. Each pothole candidate's best evidence crop receives a visual probability, persisted in Evidence JSON and shown in the UI and PDF. This score is explicitly **display-only**: it cannot discard a no-contact pothole, confirm tyre impact or upgrade a finding status. The classical detector still controls which candidates are found; crop metrics exclude defects it misses. Restart the backend after replacing weights.

The separate `ROADREPORT_MODEL` setting controls the paired event/shock model. That model remains untrained until independently labeled, synchronized real video/IMU/contact data is collected. RDD2022 still images cannot establish camera shock, tyre contact, impact timing or no-contact performance.

## Measured pilot result

On 627 held-out crops (170 pothole, 457 negative), threshold 0.5 yielded precision **70.59%**, recall **56.47%**, F1 **62.75%**, balanced accuracy **73.86%**, and log loss **0.4010**. These are crop metrics under the limited split described above, not full-video detection or shock-confirmation accuracy. Training used 8,959 crops and validation 2,710.
